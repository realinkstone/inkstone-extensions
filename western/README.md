# Western

Extensions for western series, films and cartoons. Each folder is one extension, `<id>/index.js`, with a `getVideos` method that returns the streams of an episode. All the video folders (`anime/`, `donghua/`, `drama/` and `western/`) use the same format and `medium: "anime"`.

A video extension is filed here when the first word of its description in `versioning.json` is `Western`.

Sumizuri plays these. Boundless skips them for now.

What is in here is listed in the main [README](../README.md) and in [`versioning.json`](../versioning.json). To add one, see [CONTRIBUTING](../CONTRIBUTING.md) and the guide in [docs/BUILD_WITH_AI.md](../docs/BUILD_WITH_AI.md).
